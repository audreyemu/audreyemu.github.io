Cyber Academy: Intro to Linux

by Audrey Emis

Linux is an extremely important tool to know as someone involved in computer science. Linux is a very popular free and open source operating system, which means it manages the communication between the software and hardware on your computer. Different machines have different ways of accessing a linux terminal and there are tons of linux commands (along with their options/flags) to cover. We are going through some basic file system traversal using essential linux commands like pwd, cd, and ls. We are also learning how to add and remove files/directories and how to read man pages effectively. There is a lot to learn about the linux operating system and going through OverTheWire's Bandit wargame is a great first step!

Slides

Challenges

We are solving levels from OverTheWire: Bandit at overthewire.org/wargames/bandit to learn and practice various fundamental linux commands.

Resources

The following are great resources to learn and practice linux commands.

  • Interactive Linux Tutorial: Made by your own ACM Cyber and ACM Teach committees, this easy to follow tutorial will get you familiar with important linux commands, while also getting familiar with Linux's mascot, Tux.
  • Top 60 Essential Linux Commands: Website listing some must-know linux commands along with quick summaries of how to use them.
  • tldr: Man pages can be really confusing and dense. tldr is a great resource since it is a simpler help page that focuses on practical examples.

Cyber Academy: Local File Inclusion

by Audrey Emis

The Linux File System has some built in directories that every directory (even seemingly empty ones) have! . represents the current directory and ../ represents the parent directory. Some web apps take file paths as inputs from users, which can lead to sensitive data being uncovered if the user puts in the right input. They can use "../" to get to parent directories, all the wayup to the root directory, where many more files are accessible. This vulnerability is caused by weak input sanitization or other interesting loopholes in the code. Today, we'll learn about LFI and work through some challenges that cover different LFI techniques!

Slides

Resources

The following are great resources for learning about LFI, mitigations, and bypasses.

  • Portswigger's Path Traversal Lesson: Portwigger is a great resource for all kinds of web security. There are explanations and challenges for LFI at this link.
  • HackTricks File Inclusion/Path Traversal: Great post that explains common LFI techniques and how to bypass certain mitigations.

Cyber Academy: Physical Pentesting

by Audrey Emis

In order for any system to be completely secure, it must be physically secure. There are various interesting techniques to bypass physical security, which we will discuss in this presentation. We will explain how locks work and why lock picking is possible before showing examples of how to exploit different vulnerable door designs. We'll go through some demos with the Flipper Zero, showing off its infrared and RFID capabilities. Social engineering also plays a big part in physical pentesting because oftentimes humans can be a vulnerable point in a system's security design.

Slides

Challenges

We have lock picking kits and a Flipper Zero for people to perform the demos on their own.

Resources

The following are great resources to learn more about physical pentesting.

  • Deviant Interview: Darknet Diaries interview with Deviant, who shares some interesting stories from his time as a physical pentester.
  • Linus Tech Tips Flipper Zero Video: Video explaining how a Flipper Zero works and what it can be used for.

Cyber Academy: File Forensics

by Audrey Emis

At their core, files are just a series of 1s and 0s: binary data that represent the contents of a file. You are probably familiar with various file types (jpeg, pdf, txt, etc.) but do you know how your computer knows the type of each file? There are a series of "magic bytes" (or file signatures) at the beginning of a file that indicate the file type, allowing your computer to handle the file appropriately. You will learn how files can be hidden in other files and how to extract them too.

Slides

Resources

The following are tools to better understand the contents of a file.

  • hexed.it: Online hex editor that decodes the values of the bytes of a file.
  • List of File Signatures: List of "magic bytes" or file signatures for different kinds of files.

Survivor @ UCLA

I have watched every season of Survivor since Season 32 Kaoh Rong in 2016. My parents were fans of the show and we would watch it together every Wednesday. At the time, I only cared about the challenges and would have my parents call me out of my room whenever a challenge came on.

But as I’ve grown, I’ve realized the challenges are the boring part. The really intriguing part of Survivor is the social dynamics it explores. You need to fit in well, but not so well that you’re considered a threat. You need to lie to people, while keeping yourself on their good side. It’s a game full of contradictions and I can’t get enough.

One day, when I was studying at Young Research Library at UCLA, I took a bathroom break and noticed a flyer on the stall door. It was promoting a club called Survivor @ UCLA. They plan, film, and produce their own mini version of the show – complete with challenges, advantages, blindsides, and one sole survivor. After some encouragement from my friends, I sent in an application to be a contestant and was accepted!

I competed on Season 5 of Survivor @ UCLA and had the most fun and stressful quarter of my life. It was really difficult getting blindsided and lying to people, but we had to remember that this was just a game and it was all in good fun.

I was able to win challenges, play an idol, and make it to the finale. My puzzle skills, loyal reputation, and social adaptation carried me through the season. My main focus was on managing my threat level – making people think of me as a number instead of a threat. I also set up lots of 1:1 talks with people, making deeper connections and earning more trust. I always ensured there was at least 1 bigger threat in front of me up until the last vote, where I could be the frontrunner going into the finale. I won’t spoil how the season ends.

Season 5 is scheduled to be uploaded to Survivor @ UCLA’s youtube channel in 2025/6, but you can view this sneak peak of episode 1: Survivor @ UCLA: One World - Episode 1

You can find more information at this website: Survivor @ UCLA - Season 5 and find edited episodes here: YouTube - Survivor UCLA

It’s a really unique club and I am very grateful to have found it during my time at UCLA. We’ll see if it prepares me for maybe competing on the real show someday!
