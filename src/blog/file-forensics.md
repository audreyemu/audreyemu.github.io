# Cyber Academy: File Forensics
by Audrey Emis

At their core, files are just a **series of 1s and 0s**: binary data that represent the contents of a file. You are probably familiar with various file types (jpeg, pdf, txt, etc.) but do you know how your computer knows the type of each file? There are a series of "magic bytes" (or file signatures) at the beginning of a file that indicate the file type, allowing your computer to handle the file appropriately. You will learn how files can be hidden in other files and how to extract them too.

## Resources
The following are tools to better understand the contents of a file.
- [hexed.it](https://hexed.it/): Online hex editor that decodes the values of the bytes of a file.
- [List of File Signatures](https://en.wikipedia.org/wiki/List_of_file_signatures): List of "magic bytes" or file signatures for different kinds of files.
