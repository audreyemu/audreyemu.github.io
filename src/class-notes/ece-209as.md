# Advanced and Secure Computer Architecture Notes

In Spring 2024, I took my first graduate level class called ECE 209AS, which covered Advanced and Secure Computer Architecture. I have summarized my notes from this class.

## Background
- Hardware is not inherently secure
- Adding more features to a system makes it more complex -> more bugs!
- Improving performance/efficiency introducing more sharing -> opportunity for side channels
- Main ideas/tools in computer architecture
    - Abstraction
    - Make common case fast
    - Parallelism (executing multiple tasks at once)
    - Pipelining (dividing instructions into sequential steps)
    - Prediction/Speculation (executing code speculatively)
    - Memory Hierarchy
